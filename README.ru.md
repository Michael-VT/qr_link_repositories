# QR Link Repositories

Скрипт на Python, который создаёт автономную HTML-галерею ваших репозиториев на GitHub с QR-кодами и карточками предпросмотра OpenGraph.

[English](README.md) | [Українська](README.uk.md) | [Português](README.pt.md) | [Deutsch](README.de.md) | [Français](README.fr.md)

## Что делает скрипт

1. Получает список публичных репозиториев указанного пользователя GitHub через REST API (постранично, сортировка по дате обновления).
2. Генерирует QR-код для URL каждого репозитория и встраивает его как base64 PNG.
3. Загружает картинку предпросмотра OpenGraph для каждого репозитория (через `opengraph.githubassets.com`).
4. Создаёт HTML-страницу с тёмной темой и адаптивной сеткой карточек. **Все данные встроены в файл — никаких внешних ресурсов и серверов не требуется.**
5. Записывает результат в `repos_gallery.html`.

Архивные и отключённые репозитории пропускаются автоматически.

## Требования

- Python 3.7+
- `requests`
- `qrcode`
- `Pillow` (PIL)

Установка зависимостей:

```bash
pip install requests qrcode Pillow
```

## Настройка

Измените константы в начале файла `scriptn1.py`:

| Константа | По умолчанию | Описание |
|---|---|---|
| `USERNAME` | `"Michael-VT"` | Имя пользователя GitHub |
| `OUTPUT_HTML` | `"repos_gallery.html"` | Имя выходного файла |
| `MAX_REPOS` | `50` | Максимальное количество репозиториев |
| `QR_SIZE` | `160` | Размер QR-кода в пикселях |
| `IMG_SIZE` | `110` | Размер миниатюры предпросмотра |

## Запуск

```bash
python scriptn1.py
```

Скрипт:
1. Получит репозитории с GitHub.
2. Сгенерирует QR-коды и загрузит превью.
3. Запишет `repos_gallery.html` в текущую директорию.

Откройте `repos_gallery.html` в любом браузере для просмотра галереи.

## Как добавить ссылку из других проектов

Чтобы сослаться на галерею из README другого репозитория:

### Markdown

```markdown
[Галерея моих репозиториев](https://htmlpreview.github.io/?https://github.com/Michael-VT/qr_link_repositories/main/repos_gallery.html)
```

Если вы используете GitHub Pages для этого репозитория:

```markdown
[Галерея моих репозиториев](https://michael-vt.github.io/qr_link_repositories/repos_gallery.html)
```

### HTML

```html
<a href="https://htmlpreview.github.io/?https://github.com/Michael-VT/qr_link_repositories/main/repos_gallery.html">
    Галерея моих репозиториев
</a>
```

### Совет по QR-коду

Вы также можете сгенерировать QR-код, указывающий на URL размещённого `repos_gallery.html`, и встроить его в другие проекты, печатные документы или презентации.

## Предпросмотр результата

Сгенерированная страница — адаптивная сетка с тёмной темой. Каждая карточка содержит:
- QR-код со ссылкой на репозиторий
- Название репозитория (кликабельная ссылка)
- Описание
- Картинку предпросмотра OpenGraph (если доступна)
- Количество звёзд и основной язык

## Лицензия

Проект предоставляется как есть для личного использования.
