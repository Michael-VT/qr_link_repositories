# QR Link Repositories

Скрипт на Python, який створює автономну HTML-галерею ваших репозиторіїв на GitHub із QR-кодами та картками попереднього перегляду OpenGraph.

[English](README.md) | [Русский](README.ru.md) | [Português](README.pt.md) | [Deutsch](README.de.md) | [Français](README.fr.md)

## Що робить скрипт

1. Отримує список публічних репозиторіїв вказаного користувача GitHub через REST API (посторінково, сортування за датою оновлення).
2. Генерує QR-код для URL кожного репозиторію та вбудовує його як base64 PNG.
3. Завантажує зображення попереднього перегляду OpenGraph для кожного репозиторію (через `opengraph.githubassets.com`).
4. Створює HTML-сторінку з темною темою та адаптивною сіткою карток. **Усі дані вбудовано у файл — жодних зовнішніх ресурсів чи серверів не потрібно.**
5. Записує результат у `repos_gallery.html`.

Архівні та вимкнені репозиторії пропускаються автоматично.

## Вимоги

- Python 3.7+
- `requests`
- `qrcode`
- `Pillow` (PIL)

Встановлення залежностей:

```bash
pip install requests qrcode Pillow
```

## Налаштування

Змініть константи на початку файлу `scriptn1.py`:

| Константа | Типово | Опис |
|---|---|---|
| `USERNAME` | `"Michael-VT"` | Ім'я користувача GitHub |
| `OUTPUT_HTML` | `"repos_gallery.html"` | Ім'я вихідного файлу |
| `MAX_REPOS` | `50` | Максимальна кількість репозиторіїв |
| `QR_SIZE` | `160` | Розмір QR-коду у пікселях |
| `IMG_SIZE` | `110` | Розмір мініатюри попереднього перегляду |

## Запуск

```bash
python scriptn1.py
```

Скрипт:
1. Отримає репозиторії з GitHub.
2. Згенерує QR-коди та завантажить попередні перегляди.
3. Запише `repos_gallery.html` у поточну директорію.

Відкрийте `repos_gallery.html` у будь-якому браузері для перегляду галереї.

## Як додати посилання з інших проектів

Щоб послатися на галерею з README іншого репозиторію:

### Markdown

```markdown
[Галерея моїх репозиторіїв](https://htmlpreview.github.io/?https://github.com/Michael-VT/qr_link_repositories/main/repos_gallery.html)
```

Якщо ви використовуєте GitHub Pages для цього репозиторію:

```markdown
[Галерея моїх репозиторіїв](https://michael-vt.github.io/qr_link_repositories/repos_gallery.html)
```

### HTML

```html
<a href="https://htmlpreview.github.io/?https://github.com/Michael-VT/qr_link_repositories/main/repos_gallery.html">
    Галерея моїх репозиторіїв
</a>
```

### Порада щодо QR-коду

Ви також можете згенерувати QR-код, що вказує на URL розміщеного `repos_gallery.html`, та вбудувати його в інші проекти, друковані документи чи презентації.

## Попередній перегляд результату

Згенерована сторінка — адаптивна сітка з темною темою. Кожна картка містить:
- QR-код із посиланням на репозиторій
- Назву репозиторію (клікабельне посилання)
- Опис
- Зображення попереднього перегляду OpenGraph (якщо доступне)
- Кількість зірок та основну мову
